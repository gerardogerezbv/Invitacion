Actúa como un desarrollador web senior especializado en sitios de bodas elegantes y responsive.
1
Crea una invitación web de boda moderna, elegante y responsive utilizando HTML, CSS y JavaScript puro (sin frameworks).
El proyecto debe estar listo para publicarse en GitHub Pages, Netlify o Vercel.

Debe incluir:

Diseño romántico con paleta pastel (rosa, azul, blanco y tonos suaves).
Estructura Mobile First y totalmente responsive.
Animaciones suaves al hacer scroll (fade in / reveal).
Hero con foto principal de los novios, nombres, fecha y frase romántica.
Cuenta regresiva dinámica hasta la fecha del evento.
Sección “Nuestra Historia” con timeline.
Sección de ceremonia con Google Maps embebido.
Sección de recepción con Google Maps embebido.
Cronograma del evento en formato timeline.
Galería de fotos dinámica con lightbox.
Playlist embebida de Spotify.
Formulario RSVP preparado para integración con Google Forms.
Sección de regalos con alias bancario y botón de copiar.
Botón flotante de WhatsApp.
Botón de volver arriba.

Requisitos técnicos:

Código limpio y separado en 3 archivos: index.html, style.css, script.js.
JavaScript sin frameworks.
Evitar errores si faltan elementos en el DOM.
Configuración centralizada en un objeto CONFIG en JS.
Carga optimizada y sin bloqueos.

Estilo visual:

Elegante, minimalista, romántico.
Tipografía serif para títulos y sans-serif para textos.
Sombras suaves y bordes redondeados.
Animaciones sutiles y naturales.

Debe comportarse como una landing page de invitación premium de nivel profesional.
